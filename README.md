# 📚 Mathematics Repository

Welcome to the **Mathematics** repository! This repository is your ultimate resource for various mathematical concepts, algorithms, and structures. Whether you're a student, teacher, or enthusiast, you'll find valuable information here.

## 📂 Folder Structure

- **📊 Graph**
  - `Graph.txt`: All about graph theory including definitions, types, and algorithms.

- **📐 Geometry**
  - **🏠 Polygon Area**: Methods and algorithms for calculating polygon areas.

- **🔄 Sorting**
  - `MergeSort`: 📈 Implementation of Merge Sort algorithm.
  - `QuickSort`: 📉 Implementation of Quick Sort algorithm.

- **📈 Statistics**
  - `Mode`: Methods to calculate the mode of a dataset.

- **🔢 Number**
  - `Prime`: Algorithms to determine prime numbers and related properties.

## 🧮 Graph Theory

Graph theory is fundamental to mathematics and has numerous applications. In `Graph.txt`, you'll discover:

- 📝 Definitions and basic components of graphs.
- 🔄 Special types of edges: Self loops and parallel edges.
- 📚 Types of graphs: Simple, multi-graphs, pseudographs, directed, and undirected.
- 🔢 Vertex degrees: Degree, in-degree, and out-degree.
- 📊 Subgraphs: Subgraphs, induced subgraphs, and spanning subgraphs.
- 🔗 Connectivity: Connected and disconnected graphs, components.
- ⭐ Special graphs: Complete, cycle, path, bipartite.
- 🗂 Graph representations: Adjacency matrix, adjacency list, incidence matrix.
- 🧠 Graph algorithms: BFS, DFS, Dijkstra's, Kruskal's, Prim's.
